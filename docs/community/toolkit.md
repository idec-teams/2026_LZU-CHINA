# Small resources. Useful exchanges.

Version 0.1 · Prepared 8 October 2026 · Team-created drafts for peer testing.

[Download all four resources as ZIP](../assets/community/community-kit-v0.1.zip){ .md-button .md-button--primary download }

## Run a learning session

The 25-minute activity asks learners to choose between four abstract options, change an evaluation goal and explain why their choice changes. It requires paper and discussion, not biological materials. The invented scores match the [interactive learning lab](../learn/index.md).

[English–Chinese facilitator guide](../assets/community/workshop-en-zh.txt){ download }

Use the answer guide and access suggestions. Record unclear instructions and changes. This draft has not yet been tested with external teams; do not describe it as a completed outreach event.

## Review a resource

Exchange one page or teaching resource. A reviewer restates the question, traces a claim, checks accessibility and proposes one concrete change. The author records a response and invites a recheck.

[Download the bilingual peer-review template](../assets/community/peer-review.txt){ download }

A useful review need not be positive. An unresolved issue should remain visible. Do not treat another team’s review as official endorsement.

## Leave a useful record

The blank contribution log tracks dates, versions, needs, contributions, evidence links, permissions, feedback, revisions and follow-up. It contains no invented partner or event entries.

[Download the CSV contribution log](../assets/community/contribution-log.csv){ download } · [Download the bilingual handoff template](../assets/community/handoff.txt){ download }

Only add actual events. Obtain agreement before publishing names or quotations; a public record can describe the change without disclosing private conversations.
